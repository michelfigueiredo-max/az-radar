Arquitetura Técnica
6 camadas desacopladas. Adapters plug-and-play. Cache Redis por fonte. Audit log LGPD com hash SHA-256.
Camadas do Sistema
1
Clientes
Consumidores da API
Web/App · ERP · API parceiro · White-label
Autenticam via JWT/OAuth2. Rate limiting por client_id. Payload: { cnpj, plano, campos_solicitados }.
↓
2
API Gateway
Ponto de entrada único
Auth · Rate limit · Auditoria LGPD · Versionamento
Versionamento: /v1/ /v2/. Novos campos sempre em data.{categoria} — retrocompatibilidade garantida. Audit log: tenant_id, user_id, doc_hash (SHA-256), fontes_acessadas[], justificativa, ip_origem, timestamp. CPF/CNPJ nunca em texto puro.
↓
3
Core — Resolver + Orchestrator
Decisão e coordenação
Normalização · Orquestração · Fan-out
Resolver: valida e normaliza CPF/CNPJ. Retorna 400 se inválido. Orchestrator: decide quais adapters acionar baseado no plano do usuário e tipo de documento. Executa adapters do Grupo A em paralelo (fan-out). Adapters do Grupo B acionados por plano.
↓
3b
Cache Redis
TTL por fonte
HIT → resposta imediata · MISS → aciona adapters
Chave: {adapter_id}:{doc_hash}. TTL varia por fonte (12h a 89 dias). BNMP TTL 12h (mandado pode ser revogado). SINIC/PF TTL 89 dias (certidão válida 90 dias).
↓
4
Adapter Layer
Contrato único para todas as fontes
Plug-and-play · Cada fonte = 1 adapter
Cada adapter implementa: query(doc, params) → AdapterResult e healthCheck() → boolean. Falha de um adapter não derruba o resultado — retorna status 'unavailable'. Novos adapters não exigem mudança no Orchestrator.
↓
5
Fontes Externas
APIs, scrapers, RPAs
17+ fontes V1 · Todas gratuitas ou mínimas
Receita Federal · PGFN · CNJ DataJud · TST · BNMP · SINIC/PF · SEEU · MPs (~15 UFs) · DOU · CAGED · PNCP · CGU · CEMADEN · ANTT · CVM · Brapi · LLM (veredicto e operações)
↓
6
Cross-cutting
Serviços transversais
LGPD · Observabilidade · Quota · Schema registry
Observabilidade: métricas por adapter (latência, disponibilidade, hit rate). Quota: controle de cota por plano. Schema registry: garante retrocompatibilidade do contrato. LGPD: direito de exclusão via hash — apaga dado sem precisar saber o CPF/CNPJ original.
Contrato do Adapter
interface Adapter { // Identificação id: string; // ex: 'bnmp-cnj-mandados' version: string; // ex: '1.2.0' // Consulta principal query(doc: string, params: QueryParams): Promise<AdapterResult>; // Health check para monitoramento healthCheck(): Promise<boolean>; } interface AdapterResult { source: string; // id do adapter timestamp: string; // ISO 8601 status: 'ok' | 'error' | 'not_found' | 'unavailable'; data: Record<string, unknown>; // dado retornado ttl_seconds: number; // para o Redis }

Roadmap Técnico
O que construir em qual ordem. Cada fase tem critérios de passagem explícitos.
V1 — MVP (0–6 meses) · "Serasa que explica"
SPRINT 1 — Fundação (sem. 1–4)
→ Gateway JWT + Redis + adapters infra → Adapter Receita Federal → Adapter PGFN → Adapter CGU (CEIS/CNEP) → Motor de score básico (3 camadas) → Home page split-screen
SPRINT 2 — Criminal (sem. 5–8)
→ DataJud + filtro classes criminais → TST/CSJT trabalhista → BNMP/CNJ (mandados de prisão) → RPA SINIC/PF (antecedentes) → SEEU/CNJ (execução penal) → Scraping MPs (~15 UFs) → DOU + LLM operações policiais
SPRINT 3 — Motor (sem. 9–12)
→ Score 10 camadas completo → 5 padrões de fraude societária → Score preditivo de RJ → Motor de grupo econômico → CAGED + CEMADEN/INPE → LLM veredicto em linguagem direta
SPRINT 4 — Balanço V1 (sem. 13–20)
→ Parser upload PDF/Excel/SPED → CVM DFP/ITR/FRE/IPE + Brapi → 6 indicadores + régua → DRE + ciclo + regime + valuation → Ecossistema (barra + cards) → CEO table + O que fazer/NÃO fazer
V2 — Produto Completo (6–18 meses) · "Inteligência de contraparte"
Serasa PJ + CENPROT · Benchmark setorial real CVM · PCs estaduais (Judit/Netrin) · Glassdoor scraping · Governança CVM FRE · Macro & Futuro LLM · IA fatos relevantes CVM em tempo real · Monitoramento de carteira R$49–149/mês · Simulador DCF · Análise de disrupção (integrar demo) · White-label escritórios · Score ESG automático · SPED ECD/ECF parser
V3 — Infraestrutura de Dados (18–36 meses) · "Rede coletiva B2B"
Rede coletiva B2B anonimizada (k-anonimato k≥10) · Motor preditivo ML próprio (score 90 dias) · Open Finance via TecnoSpeed · BigDataCorp grafo profundo · Timeline M&A interativa · Mapa geográfico D3.js · Crédito estruturado B2B (bancos/FIDCs)
Critérios de Passagem V1 → V2 → V3
Para lançar V2
✓ 100 clientes pagantes em 90 dias ✓ NPS > 50 ✓ Custo/consulta < R$0,80 ✓ 1 escritório usando white-label ✓ Uptime 99,5% últimos 30 dias ✓ Dev sênior ou co-fundador técnico
Para lançar V3
✓ 1.000 clientes ativos ✓ Retenção mensal > 60% ✓ 10+ escritórios white-label ✓ MRR > R$100k ✓ Uptime 99,9% ✓ Time de 3+ devs + data engineer
KPIs V3
→ 5.000+ clientes ativos → MRR > R$500k → 100+ escritórios white-label → Custo/consulta < R$0,20 → Rede coletiva > 1.000 empresas → Churn < 5%
